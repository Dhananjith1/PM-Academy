# Deployment Guide

PM Academy uses GitHub Pages from the root of the main branch. Keep the existing Pages publishing configuration unchanged.

The repository root should contain:
- index.html
- favicon.svg
- og-preview.png
- README.md
- PORTFOLIO_DESCRIPTION.md
- RIGHTS_AND_ATTRIBUTION.md
- PRIVACY.md
- VALIDATION_REPORT.md
- CHANGELOG.md
- DEPLOYMENT_GUIDE.md
- LICENSE

After each update, check the Pages deployment workflow and manually open https://dhananjith1.github.io/PM-Academy/ in a private/incognito window. Recheck lesson navigation, EVM calculator, quiz, glossary, project overview, official source links, and mobile layout.

Do not upload the ZIP archive itself as the website root. Certification requirements, software features, licences, and intellectual-property guidance can change and should be reviewed periodically.
