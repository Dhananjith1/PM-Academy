Project Overview

Project Background & Educational Purpose

1. Problem & Purpose

The Problem: Formal reference standards and comprehensive certification preparation courses can often be lengthy or costly, and learners benefit from a practical, interactive primer connecting delivery governance with everyday tools.

The Purpose: Create an accessible, static educational application with no application backend or JavaScript framework that teaches core project management mechanics, agile practices, EVM mathematics, and tool selection in clear, conversational English.

2. Target Audience

• Junior Project Managers, Associate PMs, and Project Coordinators seeking quick practical references.

• Software engineers, tech leads, and founders wanting structured delivery methodologies.

• Students preparing for formal certification studies who need a conceptual foundation.

3. Key Features

• 27 Modular Lessons in 6 Progressive Parts: Covering Foundations, Planning, Risk & Change, Agile Frameworks, PM tool ecosystem (12 tool overviews), and Leadership & Career paths.

• Live EVM Mathematical Calculator: Instant recalculation of CV, SV, CPI, SPI, and EAC with automated health interpretations.

• Interactive Knowledge Check: 13 concept and calculation questions, including an EVM calculation, with explanatory feedback.

• Instant Glossary Filter: Client-side instant keyword lookup across 35 fundamental PM concepts.

• Progress Persistence: Browser localStorage stores completed lesson IDs in the current browser; progress is not synchronized across browsers or devices.

Full technical specifications, architectural choices, and delivery documentation are available in the repository.
