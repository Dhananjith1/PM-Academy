Earned Value Management (EVM)

A practical guide to comparing planned work, completed work, and actual cost using Earned Value Management.

What is Earned Value Management?

Earned Value Management (EVM) integrates scope, schedule, and cost information to understand performance against approved baselines. It compares the budgeted value of work planned, the budgeted value of work actually completed, and the actual cost of that work.

The three core EVM values

  • Planned Value (PV): budgeted value of work scheduled by the status date.
  • Earned Value (EV): budgeted value of work actually completed by the status date.
  • Actual Cost (AC): cost actually incurred for that completed work.

Core formulas

  • Cost Variance (CV) = EV − AC. Negative means completed work cost more than its budgeted value.
  • Schedule Variance (SV) = EV − PV. Negative means less budgeted work value was earned than planned.
  • Cost Performance Index (CPI) = EV ÷ AC. Below 1.0 indicates lower cost efficiency than planned.
  • Schedule Performance Index (SPI) = EV ÷ PV. Below 1.0 indicates earned value is behind planned value.
  • Estimate at Completion (EAC) = BAC ÷ CPI when current cost efficiency is assumed to continue. BAC is Budget at Completion.

Worked example

Assume BAC is $100,000, PV is $50,000, EV is $40,000, and AC is $50,000 at the status date.

  • CV = $40,000 − $50,000 = −$10,000.
  • SV = $40,000 − $50,000 = −$10,000.
  • CPI = $40,000 ÷ $50,000 = 0.80.
  • SPI = $40,000 ÷ $50,000 = 0.80.
  • EAC = $100,000 ÷ 0.80 = $125,000, under the stated assumption.

Common interpretation mistakes

EVM schedule variance is expressed in budget units, not calendar days. SPI is an index, not a direct forecast of the finish date. CPI and SPI require credible baselines and progress rules. When AC or PV is zero, the corresponding index cannot be calculated by division. Other EAC methods may be appropriate when future work differs from past performance.
