# Privacy Notice

**PM Academy:** https://dhananjith1.github.io/PM-Academy/  
**Last reviewed:** 11 November 2026

## What the site does

PM Academy is a static educational website. The reviewed source does not include user accounts, personal-information submission forms, advertising pixels, or an analytics integration.

## Local lesson progress

When a visitor marks a lesson complete, the site stores that lesson's numeric identifier in that browser's localStorage. This data remains in that browser profile and is not synchronized across devices by PM Academy. It may be removed by clearing the browser's site data.

The EVM calculator and glossary search operate in the browser. Visitors should not enter confidential project, client, financial, or personal information into examples.

## External services

The page requests web fonts from Google Fonts. A visitor's browser makes a request to Google's font service to retrieve those fonts; Google's own privacy terms apply to that request. The site also links to external organizations and product websites. Those websites have their own privacy policies and practices.

## Hosting

The site is published using GitHub Pages. GitHub processes requests to provide and secure its hosting service under its own terms and privacy statement. PM Academy does not control GitHub's infrastructure or external linked sites.

- [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-privacy-statement)
- [Google Privacy Policy](https://policies.google.com/privacy)

## Changes

This notice should be updated if analytics, forms, accounts, external embeds, cookies, or other data-processing features are introduced.
