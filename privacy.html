Privacy and browser data

Privacy Notice

Last updated: 11 November 2026. This notice describes the current behaviour of this independent, static educational website. It is not a statement that the site has been legally certified or reviewed by a regulator or lawyer.

Information the website asks you to provide

The site currently has no account registration, contact form, newsletter, payment checkout, or advertising form. The site's own code does not ask visitors to submit names, email addresses, or personal project records. Do not enter confidential client, employer, financial, or personal information into learning examples.

Browser storage

When you mark a lesson complete, the site stores that lesson's numeric identifier in your browser's localStorage (currently using the pmDone_v3 key, with a fallback read of pmDone_v2). This lets the browser remember lesson progress on that browser profile. The progress is not sent to the site's owner by this feature and is not synchronised between devices.

The visitor counter also uses localStorage keys to remember whether the current browser profile has already been counted, coordinate simultaneous tabs, and cache the displayed total. Clearing site data, using a different browser/device, or using a temporary/private browser profile may cause the same person to be counted again. Several people sharing one browser profile may be counted only once. The displayed figure is an approximate count of browser profiles, not a verified count of distinct people.

The EVM calculator, glossary search, lesson navigation, and quiz operate in the browser. Quiz answers and calculator entries are not deliberately submitted to a website backend by these features.

Optional external visitor-counter service

The approximate visitor counter runs automatically when a public learning page is opened. The site contacts countapi.mileshilliard.com to maintain one aggregate count per persistent browser profile. The browser stores a small localStorage marker so repeat visits from that same browser profile do not add another unique-browser count. This counter has no on/off button.

On the first visit from a browser profile, the browser uses the provider's /api/v1/hit/ endpoint to increment the aggregate. Later page loads use /api/v1/get/ to read the total without incrementing it again. Clearing browser storage, using another browser, or using another device can result in the same person being counted more than once.

When the counter contacts the external service, that provider can receive the connection's IP address and standard technical request information, such as request headers and request time. The website's counter request does not append a visitor's name, email address, or account details. The provider's operator, hosting location, server-side logging, retention period, deletion process, and privacy terms have not been independently verified for this project. The site owner therefore cannot promise what the provider logs or retains.

If browser storage is unavailable, the counter cannot reliably recognise a returning browser profile, so the site does not send a count request from that page. The displayed figure is an approximate count of browser profiles, not a verified count of individual people.

Website hosting and external links

The site is hosted using GitHub Pages. When your browser requests a page or file, GitHub receives the request and may process technical information such as IP address, browser information, and request logs under its own privacy and service terms. The site owner does not control GitHub's hosting infrastructure. Read the GitHub Privacy Statement.

Other external websites are not embedded or automatically loaded by the learning pages; they are contacted when you choose to follow an external link. Those providers apply their own privacy practices. The external counter provider is contacted automatically when a public learning page is opened, to maintain and display the aggregate count.

The site's own code does not deliberately set advertising cookies or load advertising pixels, a general-purpose third-party analytics SDK, remotely hosted fonts, or embedded social-media widgets. This does not determine what GitHub or the external counter provider may do as part of delivering their services.

Privacy questions or requests

A dedicated private privacy-request contact channel has not yet been configured for this project. Do not post personal or confidential information in public GitHub issues. This is a point that the site owner must address before relying on the site for any data-processing activity that requires a formal privacy contact or request-handling process.

Data-protection law status

The Sri Lankan Personal Data Protection Act has been amended, and the Data Protection Authority's published notice states that Extraordinary Gazette No. 2498/16 sets 1 January 2027 as the commencement date for section 2, section 3, Part I, and Part III. The Authority also states that Part II and Part VII are not yet in force as at the date of this notice. This paragraph is a dated summary, not legal advice or a determination of which obligations apply to this project. Consult the Authority's current notices and a qualified adviser for the current legal position.
