Common Project Management Questions

What is project management?

Project management is the coordinated application of knowledge, skills, tools, and methods to deliver agreed project outcomes. Start with the project management basics guide.

How do I create a project plan?

Define the outcome and scope, break deliverables into a Work Breakdown Structure (WBS), sequence activities, estimate time and cost, and plan risks and communication. See the project planning guide.

Where can I find free project management templates?

Use adaptable starting points for a project charter, project plan, WBS, risk register, RACI matrix, RAID log, and status report in the free template collection.

What is a Gantt chart and critical path?

A Gantt chart shows activities against time. The Critical Path Method analyses dependencies and durations to identify the longest path through a project schedule. Read the project schedule guide.

What is IT project management?

IT project management coordinates technology work such as software, websites, system upgrades, migrations, testing, releases, and service handover. Explore the IT project management guide.

What skills does a project manager need?

Planning, communication, organisation, stakeholder coordination, critical thinking, and risk awareness are useful foundations. See the beginner project manager career guide.
