About PM Academy

Purpose & Mission: PM Academy was created to demystify project management. Heavy 800-page textbooks and costly preparatory courses often overwhelm beginners. This platform condenses core PM principles, EVM mathematics, and software delivery workflows into a clean, practical, and highly accessible format.

Target Audience: Aspiring project managers, junior project coordinators, software engineers, designers, startup founders, and students preparing for formal CAPM® or PMP® journeys.

Portfolio Case Study

PM Academy — Project Overview & Architecture

1. Problem & Purpose

The Problem: Project management standards (such as PMI's PMBOK Guide or PRINCE2) are often perceived as dense, abstract, and separated from day-to-day software tools like Jira, Trello, and Sheets. Learners frequently struggle with EVM calculations and determining how predictive and agile frameworks interrelate.

The Purpose: Build a responsive, zero-friction single-page educational application that bridges foundational project theory with real-world execution, providing 27 modular lessons, interactive calculators, an instant glossary lookup, and scenario-based quiz testing.

2. Target Audience

• Junior Project Managers & Project Coordinators needing quick reference guides.

• Cross-functional team leads (developers, designers, operations) leading sprints or client deliverables.

• Students preparing for formal certification prerequisites (CAPM®, PMP®).

3. Key Features

• 27 Modular Lessons in 6 Parts: Foundations, Planning, Risk & Change, Agile/Scrum Frameworks, PM Tools (12+ breakdown), and Leadership & Careers.

• Live EVM Calculator: Real-time evaluation of CV, SV, CPI, SPI, and EAC with automated health status explanations.

• Interactive Scenario Quiz: 12 comprehensive questions featuring detailed explanations for both correct and incorrect choices.

• Searchable Glossary: Instant client-side search across 30+ fundamental PM concepts and metrics.

• Progress Persistence: Browser LocalStorage synchronization preserving completed lesson markers.

4. Planning, Architecture & Delivery

• Tech Stack: Vanilla HTML5, modern CSS custom properties, and modular ES6 JavaScript.

• Design System: Clean typography (Fraunces & Plus Jakarta Sans), accessible color contrast ratios, and responsive CSS grid/flexbox layouts.

• Zero-Dependency Philosophy: Engineered without heavy frontend frameworks to guarantee sub-second load times and zero build-step overhead on GitHub Pages.

5. Testing & Future Roadmap

• Testing: Validated across mobile/desktop viewports, verified EVM calculation precision, tested keyboard navigation accessibility.

• Planned Improvements: Downloadable PM starter templates (Project Charter, Risk Register, RACI Matrix), dark mode theme toggle, and expanded PMP mock exam categories.
