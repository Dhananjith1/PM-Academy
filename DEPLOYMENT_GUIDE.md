# Deployment Guide

This repository uses GitHub Pages from the root of the main branch. Keep that publishing configuration unchanged.

The repository root should contain index.html, favicon.svg, og-preview.png, README.md, PORTFOLIO_DESCRIPTION.md, VALIDATION_REPORT.md, CHANGELOG.md, DEPLOYMENT_GUIDE.md, and LICENSE.

After a commit is published, open https://dhananjith1.github.io/PM-Academy/ in a private/incognito window. Check lesson navigation, EVM calculator, quiz, glossary, project overview, and mobile layout.

If the site does not show the new version, check Settings → Pages and the repository deployment status. Do not upload the ZIP archive itself as the website root.
