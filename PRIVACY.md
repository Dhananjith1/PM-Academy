# Privacy Notice — Project Management Study Resource

**Website:** https://dhananjith1.github.io/PM-Academy/  
**Last reviewed:** 11 November 2026

## What the site does

This is a static educational website. The reviewed site source does not include user accounts, personal-information submission forms, advertising pixels, analytics scripts, external embeds, or remotely hosted fonts.

## Local lesson progress

When a visitor marks a lesson complete, the site stores that lesson's numeric identifier in that browser's localStorage. This data remains in that browser profile and is not synchronized across devices by the website. It may be removed by clearing the browser's site data.

The EVM calculator and glossary search operate in the browser. Visitors should not enter confidential project, client, financial, or personal information into examples.

## Hosting and external links

The site is published using GitHub Pages. A visitor's browser sends requests to GitHub Pages to retrieve the site; GitHub may process technical request data, such as IP address and request logs, under its own terms and privacy statement. The site owner does not operate or control GitHub's hosting infrastructure.

The site contains links to external organizations and product websites. Those websites are not loaded automatically by PM Academy; when a visitor chooses to follow a link, the external site applies its own privacy practices.

- [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-privacy-statement)

## Changes

This notice should be updated if analytics, forms, accounts, cookies, external fonts, embeds, advertising, or other data-processing features are introduced.
