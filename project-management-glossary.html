Project Management Glossary

Quick, plain-language definitions of common project management terms, planning concepts, delivery methods, and performance measures.

Core project management terms

Project
A temporary endeavour undertaken to create a unique product, service, or result.
Deliverable
A unique and verifiable product, result, or capability produced by project work.
Stakeholder
A person, group, or organisation that can affect, be affected by, or perceive itself to be affected by a project.
Project charter
A document that formally authorises a project and gives the project manager authority within defined limits.

Planning and control terms

Scope
The work required to deliver a product, service, or result with specified features and functions.
Work Breakdown Structure (WBS)
A hierarchical decomposition of the total scope of work into deliverables and work packages.
Baseline
An approved version of a plan used as a basis for comparison and control.
Dependency
A relationship in which one activity or decision relies on another.
Critical path
The sequence of activities that determines the shortest possible project duration based on the schedule network and estimates.
Milestone
A significant point or event in a project, usually with zero duration in a schedule.
Risk
An uncertain event or condition that, if it occurs, affects one or more project objectives.
Issue
A current condition or event that requires action; unlike a risk, it already exists or has occurred.
Change control
The process for reviewing, deciding, and recording changes to project documents, deliverables, or baselines.

Earned Value Management terms

Planned Value (PV)
The budgeted value of work scheduled to be completed by a specified date.
Earned Value (EV)
The budgeted value of work actually completed by a specified date.
Actual Cost (AC)
The cost actually incurred for work completed by a specified date.
Cost Variance (CV)
EV minus AC; negative indicates an unfavourable cost variance.
Schedule Variance (SV)
EV minus PV; expressed in budget units, not calendar days.
Cost Performance Index (CPI)
EV divided by AC; a measure of cost efficiency.
Schedule Performance Index (SPI)
EV divided by PV; a measure of schedule performance in earned-value terms.
Estimate at Completion (EAC)
A forecast of total cost at completion based on a stated method and assumptions.

Agile delivery terms

Agile
An approach emphasising collaboration, feedback, adaptation, and delivery of value in increments.
Scrum
A lightweight framework for generating value through adaptive solutions to complex problems.
Sprint
A fixed-length event in Scrum during which a usable Increment is created.
Product Backlog
An emergent, ordered list of what is needed to improve a product.
Kanban
A strategy for optimising flow by visualising work, managing flow, and improving the system.
Work in Progress (WIP)
Work items that have started but are not yet finished.
